Business details

Pickup and delivery

Delivery uses Google Maps driving distance. The route distance is rounded up to the next whole kilometre, then the fee is calculated as base fee + (chargeable kilometres × per-kilometre fee).

Enter the exact shop pin coordinates from Google Maps. Enable billing and the Routes API in Google Cloud, then add a server-side key restricted to Routes API in .env. Delivery remains unavailable until the pin, prices, service radius, and key are configured.

Payment methods

Automatic GCash checkout

Live payments only: use a PayMongo sk_live_ secret key and the signing secret from the live-mode webhook. Set APP_BASE_URL to your public HTTPS site before enabling GCash. Test keys are rejected.

Maya manual payments

Never enter wallet PINs, passwords, or OTPs. Put provider secrets only in the server .env file.
